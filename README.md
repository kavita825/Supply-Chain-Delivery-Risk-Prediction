# Supply Chain Delivery Risk Prediction

##  About the Project

A machine learning project that predicts whether an order is at risk of late delivery. It uses order, shipping, customer, and warehouse-related data to identify delivery risks before dispatch.

##  Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab / Jupyter Notebook

##  Models Used

* Logistic Regression
* Random Forest
* Gradient Boosting

## Results

| Model               | Accuracy |
| ------------------- | -------: |
| Logistic Regression |      80% |
| Random Forest       |  **85%** |
| Gradient Boosting   |      75% |

Random Forest achieved the highest accuracy of **85%** on the prototype dataset.

##  Objective

To predict late-delivery risk in advance and help supply chain teams take preventive actions.
